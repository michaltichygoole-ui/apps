# Independent Apps

Recommended local folder name: `apps-site`

Languages:
- `/cs/` Czech
- `/en/` English
- `/` selects language automatically.

Apps:
- OpenRadar
- Herna
- PixelAmp
- Atmos

OpenRadar closed-test link:
https://play.google.com/apps/testing/cz.michaltichy.openradar

Each app has a product page and privacy page.
Old OpenRadar paths are retained as redirects.

You can rename the local clone independently of the GitHub repository.
For a cleaner public URL, consider renaming the repository to `apps`.

Privacy Policy

Updated: August 15, 2026

PixelAmp is a audio application published as part of Independent Apps. This policy describes the application's data practices.

1. Collection of personal and sensitive data

PixelAmp does not collect, store on remote servers, transmit, or share personal or sensitive user data. The application does not require an online account.

2. Network communication and third-party services

PixelAmp does not send personal or sensitive user data to the developer or third parties. The application does not use analytics or advertising services that collect personal or sensitive user data for those purposes.

3. Data stored locally on the device

Depending on its features, the application may store operational data only on the user's device, such as settings, application state, favorites, history, game results, or other content created while using the application. This local data is not sent to the developer.

4. Data security

Because the application does not transmit personal or sensitive user data to the developer, such data is not stored on Independent Apps servers. Local application data is kept in application storage managed by the device operating system.

5. Data retention and deletion

Independent Apps does not retain personal or sensitive user data on remote servers. Locally stored application data remains on the device until the user removes it using application or system controls, clears the application's storage, or uninstalls the application. Because the application does not create an online account or server-side user profile, there is no server account requiring a deletion request.

6. Children

The application is not designed to intentionally collect children's personal information and does not transmit users' personal or sensitive data to the developer.

7. Changes to this policy

This policy may be updated if application functionality or data practices change. If a future version begins to access, collect, or share personal or sensitive user data, this policy and the relevant Google Play declarations will be updated before that version is distributed.

8. Privacy contact

Privacy enquiries may be submitted using the developer contact email published with PixelAmp on Google Play. That contact also serves as the mechanism for questions concerning data and privacy.

9. Developer

Application developer: Independent Apps. Application name: PixelAmp.
